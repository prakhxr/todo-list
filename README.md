# To-Do List App 📝

A simple To-Do List application built using **HTML, CSS, and Vanilla JavaScript**.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `to-do.html` in your browser
